1. Get the files from NSE

Source

Open the NSE source page
What to downloadSet the date range (1M covers a month), leave Type as all, and choose Download (.csv). In the same Corporate Filings menu, Debt Centralised Database also lists Credit Rating Details and Default Payment Details; download those when you want ratings and defaults refreshed.

2. Check a file before uploading (optional)

Choose a CSV to see what the site will read from it: file type, date range, issuers and findings. Nothing is uploaded from here.

3. Upload to the site

Upload

Sign in to GitHub with the admin account, drag the CSV files in, and choose Commit changes. The site reads them, updates every issuer profile and republishes in about three minutes.
